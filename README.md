# TicTacToeApp
A Java-based Console Tic-Tac-Toe Game.
UC1: Displays the empty board using a 2D Array.
UC2: Random toss to assign X and O.
UC3: Captures player input (slot 1-9).
UC4: Converts input slot to 2D Array indices.
UC5: Validates user move to ensure it's in bounds and empty.
UC6: Update the board with the given symbol.
UC7: Allow the computer to make a random valid move.
UC8: Continue gameplay until win or draw is detected.
UC9: Detect if a player has won the game.
UC10: Detect when no moves remain and no winner exists.
